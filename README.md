This assignment contains Python programs created to practice loops, control statements, and functions.

### 1. Number Guessing Game
A simple guessing game where the user tries to guess a randomly generated number between 1 and 10.  
It uses a `while` loop along with `break`, `continue`, and `else`.

### 2. Multiplication Table Generator
A program that takes a number from the user and prints its multiplication table from 1 to 10 using a `for` loop and `range()`.

### 3. BMI Calculator
A program that takes weight and height from the user and calculates BMI using a user-defined function.
